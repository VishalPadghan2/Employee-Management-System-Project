📌 Employee Management System


📝 Project Description
The Employee Management System is a web-based application designed to manage employee-related information efficiently. It helps organizations perform CRUD operations such as adding, updating, deleting, and viewing employee details in a structured and user-friendly manner.


🚀 Features
-> Employee Registration
-> View Employee List
-> Update Employee Information
-> Delete Employee Records
-> Search Employee by ID or Name
-> Simple and User-Friendly Interface


🛠️ Technologies Used
-> Backend: Java, Spring Boot
-> Frontend: Thymeleaf, HTML, CSS, Bootstrap
-> Database: PostgreSQL
-> ORM: Hibernate / JPA
-> Build Tool: Maven


🗂️ Project Architecture
-> Controller Layer
-> Service Layer
-> Repository Layer
-> Entity Layer
-> Thymeleaf Templates


⚙️ Setup & Installation
-> Clone the repository
-> Copy code
      -> git clone https://github.com/VishalPadghan2/Employee-Management-System.git
-> Open the project in an IDE (IntelliJ IDEA / Eclipse)
-> Create a PostgreSQL database
-> Update database credentials in application.properties
-> Run the Spring Boot application
-> Open the application in a browser
      -> http://localhost:8080

      
🧪 Testing
-> All CRUD operations tested manually
-> Basic input validations implemented
